Three tools. One workflow.

    
Every knowledge card is produced by the same six-step loop.

    

      

        

          
        

        read_local_data(path)
        
Reads a CSV, JSON, Excel, or TSV file from disk. Returns schema, 5-row preview, row count, and all records.

      

      

        

          
        

        fetch_web_data(url)
        
Fetches a remote JSON API or CSV endpoint. Auto-detects format, returns the same schema + records envelope.

      

      

        

          
        

        make_card(...)
        
Renders an interactive Plotly HTML chart (line, bar, scatter, pie). Saves to ~/Desktop/cards/ with source citation.
